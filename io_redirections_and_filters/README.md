# Shell, I/O Redirections and filters

## 0-hello_world
Prints "Hello, World", followed by a new line, to the standard output.

## 1-confused_smiley
Displays a confused smiley "(Ôo)' followed by a new line.

## 2-hellofile
Displays the content of the /etc/passwd file.

## 3-twofiles
Displays the content of /etc/passwd and /etc/hosts, in that order.

## 4-lastlines
Displays the last 10 lines of /etc/passwd.

## 5-firstlines
Displays the first 10 lines of /etc/passwd.

## 6-third_line
Displays the third line of the file iacta in the working directory.

## 7-file
Creates a file with a special-character name containing Best School,
followed by a new line.

## 8-cwd_state
Writes the output of ls -la to ls_cwd_content,
overwriting the file if it already exists.

## 9-duplicate_last_line
Duplicates the last line of the file iacta in the working directory.

## 10-no_more_js
Deletes all regular .js files in the current directory and its subdirectories.

## 11-directories
Counts directories and subdirectories, including hidden ones, excluding the current and parent directories.

## 12-newest_files
Displays the 10 newest files in the current directory, one per line, sorted from newest to oldest.
