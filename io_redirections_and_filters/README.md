# Shell, I/O Redirections and filters

## 0-hello_world
Prints "Hello, World", followed by a new line, to the standard output.

## 1-confused_smiley
Displays a confused smiley "(Ôo)' followed by a new line.

## 2-hellofile
Displays the content of the /etc/passwd file.

## 3-twofiles
Displays the content of /etc/passwd and /etc/hosts, in that order.

## 4-lastlines
Displays the last 10 lines of /etc/passwd.

## 5-firstlines
Displays the first 10 lines of /etc/passwd.

## 6-third_line
Displays the third line of the file iacta in the working directory.

## 7-file
Creates a file with a special-character name containing Best School,
followed by a new line.

## 8-cwd_state
Writes the output of ls -la to ls_cwd_content,
overwriting the file if it already exists.

## 9-duplicate_last_line
Duplicates the last line of the file iacta in the working directory.

## 10-no_more_js
Deletes all regular .js files in the current directory and its subdirectories.

## 11-directories
Counts directories and subdirectories, including hidden ones, excluding the current and parent directories.

## 12-newest_files
Displays the 10 newest files in the current directory, one per line, sorted from newest to oldest.

## 13-unique
Prints words that appear exactly once in the input, sorted and one per line.

## 14-findthatword
Displays lines containing the pattern root from /etc/passwd.

## 15-countthatword
Counts lines containing the pattern bin in /etc/passwd.

## 16-whatsnext
Displays lines containing the pattern root and the 3 lines after each match in /etc/passwd.

## 17-hidethisword
Displays lines from /etc/passwd that do not contain the pattern bin.

## 18-letteronly
Displays lines from /etc/ssh/sshd_config that start with a letter, including uppercase letters.

## 19-AZ
Replaces all occurrences of A with Z and c with e from standard input.

## 20-hiago
Removes all lowercase c and uppercase C characters from standard input.

## 21-reverse
Reverses the characters of each line from standard input.

## 22-users_and_homes
Displays all users and their home directories, sorted by username.
