# Shell, init files, variables and expansions

## 0-alias
Creates an alias named ls with the value rm *.

## 1-hello_you
Prints hello followed by the current user's name.

## 2-path
Adds /action to the end of the PATH environment variable.

## 3-paths
Counts the number of directories in the PATH environment variable.

## 4-global_variables
Prints all environment variables and their values.

## 5-local_variables
Lists all local variables, environment variables, and functions.

## 6-create_local_variable
Creates a local variable named BEST with the value School.

## 7-create_global_variable
Creates a global variable named BEST with the value School.

## 8-true_knowledge
Prints the sum of 128 and the value of TRUEKNOWLEDGE, followed by a new line.

## 9-divide_and_rule
Prints the result of POWER divided by DIVIDE, followed by a new line.

## 10-love_exponent_breath
Prints BREATH raised to the power of LOVE, followed by a new line

## 11-binary_to_decimal
Converts the number stored in BINARY from base 2 to base 10, followed by a new line.

## 12-combinations
Prints all lowercase two-letter combinations in alphabetical order, except oo, one per line.

## 13-print_float
Prints the number stored in NUM with two decimal places, followed by a new line.

## 14-decimal_to_hexadecimal
Converts the number stored in DECIMAL from base 10 to base 16, followed by a new line.
